# Go Stone!!! 🎮

## תיאור המשחק / Hebrew Description
"Go Stone!!!" הוא משחק חשיבה ופאזל בלוקים מודרני בעל ממשק משחקי וצבעוני. במשחק תגררו צורות שונות לתוך הלוח, תרכיבו שורות וטורים מלאים כדי למחוק אותם, תצברו ניקוד ותשברו שיאים. המשחק כולל טיימר, רמות קושי שונות, מערכת משתמשים ולוח ניהול.

---

## Game Description / English
"Go Stone!!!" is a modern block puzzle strategy game featuring a vibrant UI. Drag and drop shapes onto the board to complete and clear full rows or columns, earn points, and beat high scores. Features include a timer, multiple difficulty levels, user accounts, and an admin dashboard.
